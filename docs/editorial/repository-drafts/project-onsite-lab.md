Interview preparation involves different activities: explaining an owned project, discussing a design, making a difficult decision, and building a feature. Reading about those activities is different from rehearsing them.

The goal is to create a local environment that makes the work of practice concrete and preserves attempts for review.

The private `onsite-lab` repository includes conversation-round practice, a technical deep dive, system design, and AI-assisted feature building. Its tools include a whiteboard, editor environments, decision logs, and optional rubric feedback.

Progress lives in the browser through IndexedDB, with import and export for backups. Optional AI tutoring and grading use the relevant attempt content; a model's proposed score remains something the learner can review and edit.

The README identifies the exercises as rehearsals rather than actual employer questions. That keeps the application useful as a practice environment without pretending to predict an interview.

The repository implements several ways to attempt and review interview work, with saved local progress. The capability is broader than a question bank: it gives each type of practice a surface on which to happen.

The personal result should follow a specific attempt and show what changed after feedback. The repository does not establish an interview outcome or a measured improvement.
