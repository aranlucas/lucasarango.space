Notes become difficult to use when every capture method creates another isolated collection. Keeping the material is only part of the job; it also needs somewhere to go when it becomes an active project or a reusable reference.

The goal is to organize imported and new notes with a lightweight structure that supports ongoing use.

The private `obsidian` repository documents a vault organized around Inbox, Journal, Projects, Areas, Resources, Archive, Templates, and Attachments. Imported Google Keep material joins that same structure rather than remaining a separate operational system.

The README points to a vault guide for workflows and local configuration. This article stays at that structural level; private note contents are not needed to explain the project.

For an agent-assisted workflow, the interesting question is how organization gets applied consistently without erasing the context or provenance of the original notes.

The documented result is a common structure for capture, active work, reference, and preserved source material. It establishes how the vault is intended to operate, not whether the organization has improved recall or planning.

The personal story should describe one repeated use—finding a note, reviewing a project, or incorporating an import—and what an agent did to help.
