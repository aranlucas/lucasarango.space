Recognizing a solution after reading it is different from choosing an approach from a new problem statement. A list of algorithm names does not show the decisions that lead from input constraints to a useful pattern.

The goal is to make those decisions explicit and put examples close enough to practice them immediately.

[LeetFlow](https://github.com/aranlucas/leetflow) provides an interactive decision flowchart for coding problems. A guided path leads toward patterns such as sliding windows, binary search, heaps, or graph traversal. Each pattern has signals, a Python template, complexity information, and curated practice problems.

The interface also supports search and locally saved learned status. That makes the flowchart an entry point into a reference library, with a lightweight way to remember what has been covered.

The value of the format is the intermediate reasoning. The learner can inspect the question that selected a branch instead of receiving only the name of an algorithm.

The repository implements a decision aid and connected practice material. It offers a concrete way to study pattern recognition without presenting a model-generated solution as the only next step.

The repository began before my December 2025 agentic chapter. A complete personal account needs to distinguish its original form from the revisions made with agents, then show where the decision tree proved useful or too simplistic.
